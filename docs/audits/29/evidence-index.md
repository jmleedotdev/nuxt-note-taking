# Issue #29 evidence index

Only current-app screenshots are stored in this repository. Figma exports, contact sheets containing designs, and downloaded design metadata must remain private and outside Git. Reference links below open the original access-controlled Figma file; they do not redistribute its images.

All app captures: Chromium, Inter, device scale factor 1, isolated test accounts. Columns are reference-size viewports (desktop 1440×900, tablet 768×1024, mobile 375×812), except `project-width-new-editor` (1280×720 / 1099×1024 / 549×812). Images are full-page, so image height can exceed viewport height. Motion is reduced and finite screenshot animations are completed; this is not an animation audit.

See [audit findings](README.md). A dash means no exact reference comparison is claimed. Desktop list-only uses the editor reference as shell context, not an exact list-only match. Archived reference frames include editing controls that the product deliberately does not expose.
