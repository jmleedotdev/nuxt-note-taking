# Personal Notes

A private note-taking space where each user owns their notes and tags. Notes are not shared with other users.

## Language

**Note**:
A user's private written entry with a title, plain-text content that preserves line breaks and blank lines, and optional tags. Changes become saved only when the user explicitly saves them.

**Tag**:
A text label attached to a note to organize it; a note may have multiple tags. Tags are private to the note's owner.

**Archived note**:
A retained note removed from the active notes list and shown in Archived Notes. Archiving requires confirmation and is reversible; an archived note must be restored before editing.
_Avoid_: Deleted note, trashed note

**Active note**:
A saved note that is not archived. The interface's All Notes list contains active notes only.

**Deletion**:
The permanent removal of a note after confirmation, without a trash or recovery feature.
_Avoid_: Archiving
